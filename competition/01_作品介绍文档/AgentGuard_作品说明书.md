# AgentGuard 智测盾作品说明书

## 1. 作品定位

AgentGuard 智测盾是面向 AI 智能体的质量、安全与行为风险自动化验证平台。它把测试过程组织为：Agent 接入、AI 用例生成、人工审核、批量执行、规则与语义联合判定、轨迹审计、攻击链分析、版本回归和报告导出。

## 2. 解决的问题

传统聊天机器人测试主要检查最终回答。Agent 还会调用工具、读取知识库、保留多轮上下文并执行工作流，因此仅看回答无法发现越权、间接注入、记忆污染和数据外泄。AgentGuard 将每一步行为记录为可追溯证据，并明确区分规则判定、语义判定和人工复核。

## 3. 核心能力

1. 多类型 Agent 资产：对话型、RAG、工具调用、工作流。
2. 测试集生成与人工审核：规则模板和可选大模型候选均需人工确认后保存。
3. 批量执行：记录输入、检索、策略、工具、输出和错误事件。
4. 规则优先混合判定：LLM 只能补充，不能覆盖确定性权限拒绝。
5. 证据驱动攻击链：节点关联 run_id、case_id 与 trace_event_ids，推断与观测分开表达。
6. 回归与报告：对比版本、指标和逐用例差异，支持 PDF、Markdown、CSV。

## 4. 双实例设计

- 实例 A：CampusGuard 确定性校园安全靶场，用于稳定复现知识污染、工具越权和策略拒绝。
- 实例 B：DifyCampus 真实大模型校园 Agent，用于验证 RAG、Tool、Memory 与多轮对话。

当前实例 A 已实际运行；实例 B 的适配器与接入约束已实现，但因缺少授权 Dify 地址和模型凭据，真实调用仍为 `BLOCKED`。

## 6. 使用方式

线上只读演示地址：https://agent-guard-kohl.vercel.app
后端 API：https://agentguard-api-three.vercel.app
生产数据库：Neon PostgreSQL（Alembic `0001_initial (head)`）
源码：https://github.com/ljtatm5-crypto/AgentGuard_-

生产写操作需要服务端操作员令牌；在设置页输入令牌后，令牌只保存在当前浏览器会话。

## 7. 安全边界

- 不测试未经授权的外部系统。
- 公网未知目标默认拒绝。
- 授权记录绑定主机、端口、作用域和 Agent。
- DNS 重绑定防护、禁止重定向和不读取系统代理。
- 高风险写入只用于虚拟数据。

## 8. 诚实性声明

当前尚未完成真实 Dify/LLM 端到端实验，原因是缺少授权环境和凭据。80 条候选用例尚未完成人工审核。作品中所有状态按 PASS、FAIL、BLOCKED、NOT_RUN 区分。
