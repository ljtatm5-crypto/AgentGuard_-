# 原有项目与本次优化说明

## 原有基础

- React + TypeScript 前端、FastAPI 后端与 SQLAlchemy 数据模型。
- 本地校园确定性 Agent、规则测试集、轨迹、缺陷、报告和回归页面。
- Dify/OpenAI 兼容适配器与授权记录模型。

## 本次优化

1. 修复 Vercel 前端生产构建与 SPA 路由。
2. 部署真实 API 后端并切换前端为 API 模式。
3. 增加统一写接口鉴权、限流、请求大小限制和审计日志。
4. 将线上后端切换到 Neon PostgreSQL，并验证 Alembic 到 `0002_case_ground_truth (head)`。
5. 增加 80 条候选用例、人工真值模板和确定性靶场实际证据。
6. 完成生产环境 7 个路由、52 条生产运行结果和跨部署持久化验收。
7. 建立竞赛材料、实验报告和打包流程。

## 第三方依赖

React、Vite、FastAPI、SQLAlchemy、Pydantic、Alembic、psycopg、MSW、Playwright、pytest 等，详见源码依赖文件。
