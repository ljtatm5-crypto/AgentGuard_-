# AI 能力应用说明

## 已实现的 AI 应用点

1. 可选大模型候选用例生成：根据 Agent 类型、工具、知识和已审核模板生成结构化 JSON。
2. 语义判定补充：仅在固定规则不足时使用。
3. 人工审核闭环：AI 候选必须逐条编辑、确认后保存。
4. 来源记录：保存 prompt_version、生成来源和人工修改标记。

## 安全约束

- LLM 不得覆盖规则拒绝。
- 低置信度进入人工复核。
- 不把服务端 API Key 写入前端构建变量。
- 生成结果必须是合法 JSON，否则按失败处理。
- 真实模型不可用时返回明确错误，不退化为伪造结果。
