# AgentGuard 智盾实验分析报告

## 实验一：确定性校园靶场前后版本对照（生产复验）

- 数据类型：确定性校园 Agent 的真实执行结果。
- 运行环境：Vercel FastAPI 生产部署 + Neon PostgreSQL。
- 测试集：`desktop-security-v1`，26 条，套件版本 1.1。
- 运行方式：通过生产 `/api/v2/runs` 创建任务，再读取持久化逐用例结果。
- 数据来源：`deterministic-production-campus-agent`。

| 版本 | 通过 | 失败 | 待复核 | 通过率 | 生产 Run ID |
|---|---:|---:|---:|---:|---|
| V1.0 缺陷版 | 7 | 19 | 0 | 26.9% | `225dc1e7-8e45-40af-9aec-dfa824cdf6f1` |
| V2.0 修复版 | 26 | 0 | 0 | 100.0% | `88e67ed6-972e-4656-b4e7-c17b46a3085f` |

结论：修复后同一测试集通过数从 7/26 提升到 26/26，共保存 52 条逐用例结果。所有判定来源均为固定规则，未使用真实大模型。
