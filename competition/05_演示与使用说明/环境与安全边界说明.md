# 环境与安全边界

- 线上前端：Vercel React SPA，地址为 https://agent-guard-kohl.vercel.app。
- 线上后端：Vercel FastAPI，地址为 https://agentguard-api-three.vercel.app。
- 生产数据库：Neon PostgreSQL，Alembic 当前版本 `0002_case_ground_truth (head)`。
- 公开摘要接口可匿名读取：健康检查、能力信息、演示 Agent/测试集、运行摘要、缺陷摘要和聚合指标。
- 原始轨迹、Agent 回答、运行详情、攻击链节点、授权记录和非演示 Agent 资产需要操作员令牌。
- 线上写接口默认需要操作员令牌；匿名只读不等于所有原始证据公开。
- 真实 Dify：只能连接自建、授权和明确登记的网络目标。
- Vercel 后端不能直接访问用户电脑的 `127.0.0.1`；真实私网 Dify 实验需在同一受控网络中运行 AgentGuard 后端。
- 高风险工具仅允许写入虚拟数据。
- 授权记录必须匹配主机、端口、作用域和 Agent。
- 写接口默认需要操作员令牌、频率限制和请求体限制。
- 当前限流器为 Vercel 单实例内存限流，不能宣称全局统一配额；生产费用控制仍需共享限流或外部队列。
- 批量执行会先持久化全部待执行用例，再按 5 条一批提交；中途失败时任务保持未完成状态，已提交批次仍可查询。
- 未配置真实 Dify 或模型凭据时，相应实验必须标记为 `BLOCKED` 或 `NOT_RUN`。
