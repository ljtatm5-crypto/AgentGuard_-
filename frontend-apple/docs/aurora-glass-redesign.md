# AgentGuard Aurora Glass 视觉系统重构

## 定位

设计定位是面向安全评测、研发评审与客户演示的智能体测试工作台。视觉语言采用苹果式浅色毛玻璃、柔和极光渐变、悬浮面板和高可读性排版；不采用黑色终端、荧光绿或高频赛博朋克效果。

设计强度为 6，动效强度为 4，信息密度为 6。优先级依次为可读性、信息架构、品牌特色、细节动效。

## CSS 架构

运行时样式从五份互相覆盖的文件收敛为三层：

1. `src/tokens.css`：字体阶梯、语义色、玻璃材质、圆角、阴影、层级和动效变量。
2. `src/aurora.css`：应用外壳、侧边栏、顶部栏、通用面板、按钮、表单、表格、标签、异步状态和命令面板。
3. `src/workspaces.css`：工作台、Agent 资产、测试工作室、执行轨迹、Evidence Flow、报告与设置，以及全部响应式规则。

`styles.css`、`apple.css`、`mobile.css`、`legibility.css`、`workspace.css` 保留在仓库中作为历史实现，但已经退出 `main.tsx` 的运行时加载链。

## Typography Tokens

| Token | 字号 | 用途 |
| --- | ---: | --- |
| `--font-xs` | 12px | 标签、非关键说明 |
| `--font-sm` | 14px | 表格正文、轨迹正文 |
| `--font-nav` | 15px | 桌面导航 |
| `--font-body` | 16px | 页面正文、表单 |
| `--font-button` | 15px | 按钮 |
| `--font-title-sm` | 24px | 面板标题 |
| `--font-title` | 34px | 页面标题 |
| `--font-metric` | 34px | 关键指标 |

新样式中不存在用于展示可读信息的 8px、9px、10px 或 11px 字号，也没有通过整体缩放解决布局拥挤。

## 页面变化

### 工作台

- 从宣传式 Hero 改为“当前验证环境 + 质量概览 + Evidence Flow”的工作台布局。
- 增加当前 Agent、Agent 类型、规则判定占比和授权边界。
- 保留统计指标、最近测试、风险分布和验证指标，所有数值仍来自现有 API 或明确的 Mock 数据。

### Agent 资产

- 强化资产卡片的身份层级、校验状态、知识库与工具数量。
- 增加悬浮反馈和更清晰的“开始测试”快捷入口。
- 保留本地安全沙盒与授权 Dify 的连接流程和确认约束。

### 测试工作室

- 放大工具栏、候选列表和编辑器字段。
- 输入框和文本域统一为 15–16px，扩大编辑空间。
- 保留 AI 候选项逐条编辑、删除、原始建议查看和人工保存流程。

### 执行任务

- 保留用例结果、行为轨迹、判定证据三栏结构。
- 中栏改成纵向证据时间线，节点标题、工具名、策略和输出可连续阅读。
- 点击轨迹节点会显示柔和聚焦光环，并在右侧同步显示当前节点与判定证据关联。
- 原始事件 JSON 仍默认折叠。

### 攻击链

- Evidence Flow 使用更清晰的节点、实线证据关系和虚线推断关系。
- 点击节点后只改变视觉焦点和证据详情，不改变后端风险结论。
- 实际观测节点与推断节点继续使用后端返回值区分。

### 报告与回归

- 修复前后对比、攻击成功率变化和逐用例差异采用更明确的语义色。
- “已修复、新增回归、仍存在、无法比较、未变化”使用不同文字、圆点和底色共同区分。

### 设置

- 保留数据来源、判定偏好和授权范围说明。
- 将演示范围表述改为“多类型智能体”，不再把产品能力限定为校园助手。

## 交互与无障碍

- 导航选中态继续使用 Motion `layoutId` 平滑移动。
- 卡片悬浮轻微上移，轨迹节点选中显示聚焦光环，链路颜色过渡为 180–260ms。
- 全部动效支持 `prefers-reduced-motion`。
- 半透明面板提供 `prefers-reduced-transparency` 和 `backdrop-filter` 不可用时的实体背景回退。
- 保留键盘焦点、Skip Link、命令面板焦点陷阱与语义标签。
