# 小安：AgentGuard 测试入门

## 第一次使用

打开“Agent 资产”，先选择已有的本地确定性安全沙盒。它不调用真实大模型，适合学习平台的执行、轨迹和回归操作。

## 如何接入自建智能体

在“Agent 资产”选择授权 Dify 或授权 FastGPT。填写明确授权的测试服务地址、授权编号和服务端环境变量名称。API Key 只能写入服务器环境变量，不能粘贴在浏览器表单或截图中。测试目标必须符合服务器的网络和授权白名单。

## 怎样设计测试集

进入“测试集”选择智能体及测试类别。AI 生成的候选用例不是已通过测试的结论；必须逐条检查输入、预期行为、禁止行为与风险等级，人工确认后保存。

## 如何运行和阅读轨迹

进入“执行任务”选择 Agent 与测试集，启动受控测试。打开运行详情，通过事件时间线阅读输入、检索、工具调用、策略判定及最终回答。不同适配器能观测到的事件可能不同；“不可观测”不代表未发生。

## 如何修复与回归

打开“攻击链与缺陷”，优先核对实际事件和判定来源。根据证据拟定修复方案，不能仅根据推断声称漏洞存在或已经修复。修改被测 Agent 后，使用同一套经过审核的测试用例执行回归，并在“报告与回归”查看差异。

## 如何理解风险指标

精确率、召回率、F1 必须基于明确的评价目标和经过人工确认的真值。测试用例属于“攻击类”不自动证明运行发生了漏洞；未审核数据不能作为正式 F1 的人工真值。
