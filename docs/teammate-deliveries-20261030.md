## 集成时额外修复

1. **Dify 真正使用固定 IP**
   B 包原先只在 OpenAI 兼容分支调用 `pinned_request`，Dify 分支仍用 `httpx` 请求原域名，会再次 DNS 解析。已改为两种远程适配器统一直连固定 IP，并新增测试。
2. **授权绑定不能因缺少 Agent 上下文而跳过**
   绑定到具体 Agent 的授权记录，在调用缺少 `agent_id` 时也必须拒绝。已修正判断并增加测试。
3. **桌面 Agent 校验和运行接入授权记录**
   `/api/v2/agents/validate` 和 `/api/v2/runs` 现在传 `db` 与 `agent_id`，授权编号必须是服务端真实有效记录。
4. **控制字号符合视觉系统**
   C 的轨迹筛选控件原本使用 12px。已提升到按钮 15px、搜索 16px，并保留横向滚动布局。
5. **CI 纳入新门禁**
   `check:trace` 纳入 CI 与 Pages 构建；浏览器主流程改为运行完整 `test:smoke`，不再只跑两份 spec。
6. **Node 测试启动器移除 shell 拼接**
   C 的脚本原先在 Windows 使用 `npx.cmd` 加 `shell: true`，会触发 Node 安全弃用警告。已改为直接调用 Playwright CLI。
