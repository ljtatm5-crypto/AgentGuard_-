# 小安 RAG 设计

## 知识集合

运行知识库来自 `backend/app/services/xiaoan/knowledge.py`，覆盖新手流程、Agent 接入、测试设计、轨迹阅读、安全修复、报告回归和安全边界。知识库与任何被测 Agent 的知识库完全隔离。

## 切片

- 按 Markdown H2 标题切分语义块。
- 超长段落按空行分段并保持顺序。
- 每个切片保存标题、来源、版本、页面路由、标签、内容哈希和 Embedding。
- 文档内容哈希变化时重建该文档切片，重复启动不会重复写入。

## Embedding

- 未配置远端模型时使用确定性本地哈希向量，保证离线与测试环境可运行。
- 配置 `AGENTGUARD_XIAOAN_EMBEDDING_URL`、模型和凭据环境变量后调用 OpenAI-compatible Embedding 服务。
- 远端调用继续使用目标范围校验，不绕过现有 SSRF 边界；失败时明确回退到本地哈希向量。

## 混合检索

1. 查询与切片按中英文 token 和中文二元组切词。
2. 关键词检索返回前 12 条。
3. 向量余弦检索返回前 12 条。
4. 使用 Reciprocal Rank Fusion 融合，并按当前页面路由加权。
5. 返回前 3–5 个引用片段。

## 回答约束

- 回答必须来自检索片段或授权事件。
- 没有来源时明确说明证据不足。
- 事件证据、教程知识和推断分别展示。
- LLM 只能整理已检索内容，不得构造事件 ID、页面路径或修复成功结论。
