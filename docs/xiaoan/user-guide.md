# 小安使用指南

## 打开小安

任意页面右下角点击“小安”。面板会识别当前页面，并给出对应的快捷问题。

## 新手教学

在总览页询问“第一次使用应该做什么”，或打开“跟着小安学”流程。每一步都提供可点击的页面入口。

## Agent 接入

在 Agent 资产页询问 Dify/FastGPT 接入、凭据配置或授权失败原因。小安只会给出已审核的操作路径，不会要求你在聊天中粘贴密钥。

## 证据诊断

在运行详情或缺陷攻击链页面选中记录，再打开小安提问“为什么失败”。小安会引用事件编号并区分实际观测和推断。

## 修复与回归

在缺陷页面打开攻击链后询问“怎样修复这个问题”。小安会返回问题、原因、影响、修复步骤、副作用和回归计划。修复必须人工确认，之后用同一测试集重新运行。

## 结果标识

- `本地知识回答`：使用本地知识检索与规则组装，没有调用外部大模型。
- `模型回答`：使用已配置的小安模型，并仍受检索来源和权限约束。
- `示例回答`：Mock 模式演示，不代表真实模型或生产测试结果。
