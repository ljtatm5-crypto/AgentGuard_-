# 小安安全设计

## 不可信输入

知识文档、用户问题、Run 回答、Trace 输出和工具结果都按不可信数据处理。知识片段不能覆盖系统指令，也不能要求小安提升权限。

## 鉴权

- 无私有上下文的基础教学聊天可匿名使用并限流。
- 携带 Agent、Run、Case、Finding 或事件上下文的请求需要现有操作员令牌。
- 反馈和来源读取继续使用服务端鉴权。

## 禁止能力

- 任意 SQL。
- 任意 URL 请求。
- 读取环境变量或输出 API Key。
- 跨用户读取私有证据。
- 自动修改策略、生产代码或测试数据。
- 自动执行高风险工具。
- 未经复测直接宣称漏洞已修复。

## 输出原则

- 事实状态分为 `observed`、`inferred`、`unavailable`。
- 修复计划固定带 `requires_human_confirmation=true`。
- 来源和事件 ID 只能从服务端检索结果产生。
- 模型服务不可用时回退到本地 grounded 回答，不伪造模型调用。
